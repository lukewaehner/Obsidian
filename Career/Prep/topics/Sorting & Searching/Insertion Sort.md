## Idea

Build the sorted portion one element at a time, inserting each new element
into its correct position among the elements already placed.

## How it works

## Implementation

## Complexity

O(n²) average and worst case; O(n) best case on nearly-sorted input.

## When to use it

Small n, nearly-sorted input, or as the base case inside a bigger sort
(many quicksort/mergesort implementations switch to insertion sort below a
size threshold).
