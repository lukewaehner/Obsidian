## Idea

Named, reusable solutions to recurring design problems — the value isn't
the code, it's the shared vocabulary ("just use a decorator here") that
lets engineers communicate a design in one word instead of a diagram.

## How it works

The patterns worth knowing by name and shape: strategy, singleton, adapter,
prototype, decorator, visitor, factory/abstract factory, facade, observer,
proxy, delegate, command, state, memento, iterator, composite, flyweight.

## Gotchas

Reaching for a pattern before the problem calls for it is the most common
misuse — a pattern should name a shape you already need, not be applied
speculatively.
