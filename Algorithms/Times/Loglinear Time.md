# Loglinear Time - O(n log n)

Time taken is $c \cdot n \log{n}$ for some constant $c$. Better than quadratic but worse than linear.

Algorithms with $n \log{n}$ runtimes are usually slightly more complicated.

**Examples:**
- Sorting algorithms like mergesort, heapsort, quicksort
- Common runtime when quadratic algorithms are improved via divide and conquer
