### Creating the page

1. **File $\rightarrow$ New $\rightarrow$ File**
2. Select **Cocoa Touch Class**, click Next.
3. Put **ShowViewController** as the class name
4. Select **UIViewController** as Subclass (should already be selected)
5. Language should be swift
6. Click Next
7. Click Create

> This should create a new ShowViewController swift file, we can design the second screen here
