## Net Present Value (NPV)

Difference between present values of benefits and costs.

$$
NPV = C_0 + \frac{C_1}{(1+r)} + \frac{C_2}{(1+r)^2} + ... + \frac{C_N}{(1+r)^N}
$$

Where:
- $C_n$ = Net cash flow at time n
- r = Project opportunity cost of capital

---

## Decision Rule

- **Accept** if NPV > 0
- **Reject** if NPV < 0
- **Indifferent** if NPV = 0

---

## Example

Two projects, required return 8%:

| Year | Project A | Project B |
| --- | --- | --- |
| 0 | -5,400 | -8,100 |
| 1 | 1,325 | 1,325 |
| 2 | 2,148 | 2,148 |
| 3 | 3,926 | 7,594 |

**Project A:**

$$
NPV = -5400 + \frac{1325}{1.08} + \frac{2148}{1.08^2} + \frac{3926}{1.08^3} = \$785
$$

**Project B:**

$$
NPV = -8100 + \frac{1325}{1.08} + \frac{2148}{1.08^2} + \frac{7594}{1.08^3} = \$997
$$

Project B has higher NPV.

---

## Key Insight

NPV estimates the value a project adds to the firm.
