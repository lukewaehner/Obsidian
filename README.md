# Second Brain

This is my personal knowledge base and "Second Brain," managed with Obsidian. It serves as a central repository for my notes, learning materials, and project documentation.

## Structure

The vault is organized into several high-level categories to keep information accessible and structured:

- **Archive**: Contains reference materials and subject-specific knowledge bases (e.g., Finance, Accounting, Investments).
- **Code**: Technical notes covering programming languages (Java, Ruby, Rust, etc.), development tools, and computer science topics like algorithms and systems.
- **Northeastern**: Academic planning, class notes, and university-related resources.
- **Professional Tools**: Career preparation materials, including interview questions, resume drafts, and job search resources.
- **Images**: Media assets used throughout the notes.

## Usage

This is a living collection of documents. Content is constantly being added, updated, and reorganized as I learn new things and refine my workflow.
