# Second Brain

This is my personal knowledge base and "Second Brain," managed with Obsidian. It serves as a central repository for my notes, learning materials, and project documentation across school, career prep, and self-study.

The vault currently holds **741 markdown notes**, organized around a Map-of-Content (MOC) architecture — every major folder has a hub note that links out to its children, so the graph view stays navigable as the collection grows.

## Structure

- **Archive/** — Holding pen for retired notes (currently empty after a recent cleanup).
- **Career/** — Interview questions, resume drafts, job sites, and professional tooling notes.
- **Code/** — Technical notes across 13 sub-topics: Algorithms, DSA, Computer Systems, Databases, JavaScript, React, Ruby (incl. Rails), Rust, Java, iOS, OOD, Neovim, and Zsh.
- **Finance/** — The largest section (~269 notes) covering Corporate Finance, Financial Accounting, Investments (incl. Behavioral Finance), and Managerial Accounting.
- **Images/** — Media assets, organized by topic to mirror the note structure.
- **Northeastern/** — Class planning and university-specific resources.
- **templates/** — 11 Templater templates (daily, meeting, MOC, and per-language scaffolds) that drive a consistent note-creation workflow.

## Workflow

The vault runs on a Templater-driven setup with the Tasks, Calendar, Homepage, Folder Note, Icon Folder, File Color, and Obsidian Git plugins. The graph view uses a Tokyo Night palette with topic-specific folder colors so the structure stays visually legible at a glance.

## Usage

This is a living collection. Content is constantly being added, updated, and reorganized as I learn new things and refine my workflow.
