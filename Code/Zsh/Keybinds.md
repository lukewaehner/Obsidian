# Emacs Mode

## Movement
- `Ctrl-a` — beginning of line
- `Ctrl-e` — end of line
- `Ctrl-f` — forward one character
- `Ctrl-b` — back one character
- `Option-f` — forward one word
- `Option-b` — back one word

## Editing
- `Ctrl-d` — delete character under cursor
- `Ctrl-h` — delete character before cursor (backspace)
- `Option-d` — delete word forward
- `Ctrl-w` — delete word backward
- `Ctrl-k` — kill from cursor to end of line
- `Ctrl-u` — kill from cursor to beginning of line
- `Ctrl-y` — yank (paste) last killed text
- `Option-y` — cycle through kill ring (after Ctrl-y)

## History
- `Ctrl-p` — previous command
- `Ctrl-n` — next command
- `Ctrl-r` — reverse incremental search
- `Ctrl-s` — forward incremental search
- `Option-.` — insert last argument of previous command

## Misc
- `Ctrl-l` — clear screen
- `Ctrl-_` — undo
- `Ctrl-x Ctrl-e` — edit command in $EDITOR
- `Ctrl-t` — transpose characters
- `Option-t` — transpose words
- `Option-u` — uppercase word
- `Option-l` — lowercase word
- `Option-c` — capitalize word

## Command Control
- `Ctrl-c` — cancel current line
- `Ctrl-z` — suspend process
- `Ctrl-d` — exit shell (on empty line)

---

**Terminal Setup:** Enable "Use Option as Meta key" in your terminal preferences (iTerm2: Profiles → Keys → Left/Right Option Key → Esc+)
