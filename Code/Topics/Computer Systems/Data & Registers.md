## Primitive data sizes
| Name          | Suffix | Bytes | Bits | C Type  |
|---------------|--------|-------|------|----------|
| byte           | b      | 1     | 8    | char      |
| word           | w      | 2     | 16   | short     |
| double word    | l      | 4     | 32   | int       |
| quad word      | q      | 8     | 64   | long      |

---

## Registers
- Registers are small, fast CPU storage
- 64-bit each
- There are 16 **general purpose registers**
- Each has sub-registers for 32/16/8-bit access

> Memory is slower — so we use registers whenever possible.
