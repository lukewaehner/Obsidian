### Week 1–2: React tightening

- **React docs learn path end-to-end**, daily.[React+1](https://react.dev/learn?utm_source=chatgpt.com)
    
- Build your “Team Tasks + Comments” app.
    
- Measure yourself honestly:
    
    - Can you explain `useEffect` dependency array _without Googling_?
        
    - Can you refactor to a custom hook where logic is duplicated?
        
    - Can you add error and loading states in 10–15 minutes, not 1 hour?
        

If not, you’re not “refreshed”.

### Week 2–3: Ruby language

- Work through Ruby intro chapters (Pickaxe or Odin’s Ruby section).[Reddit+1](https://www.reddit.com/r/ruby/comments/1ex0mbk/what_is_the_best_resource_for_learning_ruby_as_an/?utm_source=chatgpt.com)
    
- Daily kata:
    
    - Re-implement a few simple utilities using Enumerable: e.g., group tasks by status, group logs by day, implement your own `map` or `select` for practice.
        
    - Write small scripts and run them from CLI (`ruby script.rb`).
        
- Keep `ruby-doc.org` open and force yourself to look up every method you don’t recognize.[Ruby Documentation+1](https://ruby-doc.org/?utm_source=chatgpt.com)
    

### Week 3–5: Rails + API + React

- Follow Rails Guides to build a simple JSON API.[Ruby on Rails Guides](https://guides.rubyonrails.org/?utm_source=chatgpt.com)
    
- Then implement your own “Tasks API” and plug your React frontend into it:
    
    - No tutorials at this stage; only docs and occasional blog posts if you’re stuck.[DEV Community+1](https://dev.to/minchulan/building-a-full-stack-mvc-application-with-ruby-on-rails-and-react-4n9n?utm_source=chatgpt.com)
        
- Add tests (RSpec or whatever your company uses if you know it).
    

### Week 5–6: Simulate the job

- Clone one open-source Rails + React repo that looks close-ish to what you’ll be doing.
    
- Force yourself to:
    
    - Fix a bug.
        
    - Add a small feature.
        
    - Write or update tests.
        
- Time yourself and note where you get slow. Those are your weak spots.
