
> Complete workflow for creating multi-screen iOS apps with UITableView for data display and management.

---

## Process Overview

This workflow demonstrates building a contacts app with three screens:
1. **Display Screen** - Shows contacts in a table
2. **Add Data Screen** - Form to create new contacts
3. **Detail Display Screen** - Shows full contact information

---

## Implementation Steps

 1. [[Display Screen with Table]] - Setting up the main table view screen
 2. [[Add Data Screen]] - Creating the input form and validation
 3. [[Detail Display Screen]] - Displaying selected contact details

---

## Key Concepts Used

- [[UITableView]] - Displaying scrollable list of contacts
- [[Sending Data Between Screens]] - Passing contact to detail screen
- [[Sending Data Back]] - Returning new contact from add screen
- [[Navigation Controller]] - Managing screen stack
