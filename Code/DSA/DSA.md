# Data Structures & Algorithms

Fundamental data structures and algorithms for efficient problem solving.

## Data Structures

### Linear Structures
- [[Linked List]] — Sequential nodes with single pointers
- [[Doubly Linked List]] — Nodes with forward and backward pointers
- [[Stack]] — LIFO (Last In, First Out) collection
- [[Queue]] — FIFO (First In, First Out) collection

### Associative Structures
- [[Hashtable]] — Key-value storage with O(1) average access

### Hierarchical Structures
- [[Tree]] — Parent-child node relationships

## Algorithms

### Searching
- [[Code/Topics/DSA/Binary Search]] — O(log n) search on sorted data

## Complexity Reference

| Structure | Access | Search | Insert | Delete |
|-----------|--------|--------|--------|--------|
| Array | O(1) | O(n) | O(n) | O(n) |
| Linked List | O(n) | O(n) | O(1) | O(1) |
| Stack | O(n) | O(n) | O(1) | O(1) |
| Queue | O(n) | O(n) | O(1) | O(1) |
| Hash Table | — | O(1)* | O(1)* | O(1)* |
| Binary Tree | O(log n)* | O(log n)* | O(log n)* | O(log n)* |

*Average case; worst case may differ
