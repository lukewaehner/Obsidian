## Quick Reference

```ruby
# Variables
name = "Ruby"
age = 30
is_fun = true

# String interpolation
puts "Hello, #{name}!"

# Arrays and hashes
numbers = [1, 2, 3]
person = { name: "Alice", age: 30 }

# Iteration
numbers.each { |n| puts n }

# Methods
def greet(name)
  "Hello, #{name}!"
end

# Classes
class Person
  attr_accessor :name
  
  def initialize(name)
    @name = name
  end
end
```
