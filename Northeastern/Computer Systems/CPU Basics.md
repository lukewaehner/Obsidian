## What does a CPU do?
**Fetch–Decode–Execute cycle**
1. Read next instruction
2. Decode/analyze
3. Execute
4. Repeat

- Executing an instruction may change what comes next
- Instructions are sequences of `0` and `1`

## Human readability
- Writing raw binary is impractical
- Mnemonics invented → **assembly language**
- Modern practice: use **high-level languages**

## Instruction Set Architecture (ISA)
- Set of instructions a CPU understands
- Defines how software controls hardware
- Our target: [[x86_64 Architecture]]
