Quick Setup Instructions

To make buttons work:
1. Replace "YourVaultName" with your actual vault name in all links
2. Update file paths to match your folder structure
3. For Wiki links use: [[Note Name]] instead of HTML links
4. For command palette: use obsidian://show-command-palette
5. Delete this setup card when done!

Working Link Examples:
• Open note: [[Your Note Name]]
• Create note: [[Folder/New Note Name]]
• Search: obsidian://search?query=your+search
• Tag search: [[#YourTag]]
