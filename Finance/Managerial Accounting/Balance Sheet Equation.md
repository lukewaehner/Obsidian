# Balance Sheet Equation

The fundamental accounting equation showing the relationship between assets, liabilities, and stockholders' equity.

## The Core Equation

```
Assets = Liabilities + Stockholders' Equity
```

**Always in balance** - hence "balance sheet"

## What Each Component Represents

### Assets

**Definition**: Resources owned by the company that have future economic value.

**Categories**:

**Current Assets** (convert to cash within 1 year):
- Cash
- Accounts Receivable
- Inventory (Raw Materials, WIP, Finished Goods)
- Prepaid Expenses

**Non-Current Assets** (long-term):
- Property, Plant & Equipment (PP&E)
- Less: Accumulated Depreciation
- Intangible Assets (patents, trademarks)
- Long-term Investments

### Liabilities

**Definition**: Obligations the company owes to others.

**Categories**:

**Current Liabilities** (due within 1 year):
- Accounts Payable
- Salaries Payable
- Taxes Payable
- Short-term Debt

**Non-Current Liabilities** (long-term):
- Long-term Debt
- Bonds Payable
- Deferred Tax Liabilities

### Stockholders' Equity

**Definition**: Owners' claim on assets after all liabilities are paid.

**Also Called**:
- Shareholders' Equity
- Owners' Equity
- Net Worth
- Net Assets

**Formula**:
```
Stockholders' Equity = Assets - Liabilities
```

## Stockholders' Equity Components

```
Stockholders' Equity = Contributed Capital + Retained Earnings
```

### Contributed Capital

**Definition**: Investment by owners in exchange for stock.

**Components**:
- Common Stock (par value)
- Additional Paid-in Capital (amount above par)

**Example**:
```
Issued 1,000 shares at $10/share
Par value: $1/share

Common Stock:              $1,000 (1,000 × $1 par)
Additional Paid-in Capital: $9,000 (1,000 × $9 above par)
───────────────────────────────────────────────────
Total Contributed Capital: $10,000
```

### Retained Earnings

**Definition**: Cumulative profits retained in the business (not paid as dividends).

```
Retained Earnings = Beginning RE + Net Income - Dividends
```

**Connects to Income Statement**:
```
Net Income → increases Retained Earnings → increases Stockholders' Equity
```

## The Expanded Equation

```
Assets = Liabilities + Contributed Capital + Retained Earnings
```

**Further expansion**:
```
Assets = Liabilities + Contributed Capital + (Beginning RE + Revenue - Expenses - Dividends)
```

## Connection to Income Statement

**Income Statement shows**:
```
Revenue - Expenses = Net Income
```

**This Net Income flows to**:
```
Retained Earnings (Balance Sheet)
```

**Full Flow**:
```
Revenue
- Expenses
─────────────
Net Income → Retained Earnings → Stockholders' Equity
```

## Statement Relationships

### Income Statement
```
Revenue
- Expenses
─────────────
Net Income
```

### Statement of Retained Earnings
```
Beginning Retained Earnings
+ Net Income (from Income Statement)
- Dividends
─────────────────────────────────────
Ending Retained Earnings
```

### Balance Sheet
```
Assets

=

Liabilities
+ Stockholders' Equity:
    Contributed Capital
    Retained Earnings (from Statement of RE)
```

## Debits and Credits

**Fundamental Rule**: Debits must equal Credits

### Normal Balances

| Account Type | Normal Balance | Increase | Decrease |
|--------------|----------------|----------|----------|
| Assets | Debit | Debit | Credit |
| Liabilities | Credit | Credit | Debit |
| Stockholders' Equity | Credit | Credit | Debit |
| Revenue | Credit | Credit | Debit |
| Expenses | Debit | Debit | Credit |

**Memory Aid**: 
- **Debit** Assets
- **Credit** Liabilities and Stockholders' Equity

### Revenue and Expenses

**Revenue** (increases equity):
```
Dr. Cash/Accounts Receivable
    Cr. Revenue
```

**Expenses** (decreases equity):
```
Dr. Expense
    Cr. Cash/Accounts Payable
```

**Net Income** (closes to Retained Earnings):
```
Dr. Revenue
    Cr. Retained Earnings
    Cr. Expenses
```

## Transaction Impact Examples

### Example 1: Purchase Inventory on Credit

```
Dr. Inventory (Asset increases)            10,000
    Cr. Accounts Payable (Liability increases)    10,000
```

**Equation**:
```
Assets (+$10,000) = Liabilities (+$10,000) + Equity (no change)
```

### Example 2: Pay Salaries

```
Dr. Salaries Expense (Equity decreases)    5,000
    Cr. Cash (Asset decreases)                    5,000
```

**Equation**:
```
Assets (-$5,000) = Liabilities (no change) + Equity (-$5,000)
```

### Example 3: Make a Sale

```
Dr. Cash (Asset increases)                 8,000
    Cr. Sales Revenue (Equity increases)          8,000

Dr. Cost of Goods Sold (Equity decreases)  4,500
    Cr. Inventory (Asset decreases)               4,500
```

**Net Equation Impact**:
```
Assets (+$3,500) = Liabilities (no change) + Equity (+$3,500)
  Cash +8,000, Inventory -4,500 = +3,500
  Revenue +8,000, Expense -4,500 = +3,500
```

**Acme Manufacturing Co.**

## Key Insights

### 1. The Equation Always Balances

Every transaction affects at least two accounts, keeping the equation in balance.

### 2. Multiple Perspectives

The equation can be rearranged:
```
Assets - Liabilities = Stockholders' Equity
```

This shows: **Equity is the residual claim** after paying all liabilities.

### 3. Historical vs Current Value

Balance sheet shows **historical cost**, not current market value (with some exceptions).

### 4. Point in Time

Balance sheet is a **snapshot** at a specific date, unlike income statement which covers a period.

### 5. Connection to Other Statements

- **Income Statement** → Net Income → **Retained Earnings**
- **Retained Earnings** → part of **Stockholders' Equity**
- **Cash Flow Statement** → explains **Cash** balance changes
