

Detailed examples and practice problems for calculating [[Net Asset Value (NAV)]].

## Standard Formula

```
NAV = (Total Assets - Liabilities) / Number of Shares Outstanding
```

Where:
- **Total Assets** = Cash + Market Value of all securities
- **Liabilities** = Debts, expenses owed
- **Shares Outstanding** = Number of fund shares in existence

## Example 1: Mulan Fund

### Given Information
| Component | Value |
|-----------|-------|
| Cash | $0.3 million |
| Liabilities | $0.2 million |
| Shares Outstanding | 100,000 |

**Stock Holdings:**
| Stock | Shares | Price | Total Value |
|-------|--------|-------|-------------|
| Vibranium | 15,000 | $50 | $750,000 |
| Uru | 25,000 | $60 | $1,500,000 |
| Adamantium | 12,000 | $100 | $1,200,000 |

### Step-by-Step Solution

**Step 1: Calculate total stock value**
```
Stock Value = (15,000 × $50) + (25,000 × $60) + (12,000 × $100)
           = $750,000 + $1,500,000 + $1,200,000
           = $3,450,000
```

**Step 2: Calculate total assets**
```
Total Assets = Cash + Stock Value
            = $300,000 + $3,450,000
            = $3,750,000
```

**Step 3: Calculate net assets**
```
Net Assets = Total Assets - Liabilities
          = $3,750,000 - $200,000
          = $3,550,000
```

**Step 4: Calculate NAV per share**
```
NAV = Net Assets / Shares Outstanding
    = $3,550,000 / 100,000
    = $35.50 per share
```

### Answer
**NAV = $35.50 per share**

## Key Calculation Tips

### Common Pitfalls
1. **Don't forget to subtract liabilities** - It's NET asset value
2. **Include all asset types** - Cash, stocks, bonds, etc.
3. **Use market values** - Not historical cost
4. **Convert units consistently** - Match millions to millions

### Verification Steps
- ✓ Did you calculate each security position correctly?
- ✓ Did you sum all positions plus cash?
- ✓ Did you subtract liabilities?
- ✓ Did you divide by the correct share count?
- ✓ Does your answer make sense given the holdings?

## Practice Framework

When given a NAV problem:
1. **Organize data** - Create a table of holdings
2. **Calculate position values** - Shares × Price for each security
3. **Sum total assets** - All securities + cash
4. **Subtract liabilities** - Get to net assets
5. **Divide by shares** - Final NAV per share

## Applications

### For Open-End Funds
- This NAV is the exact price for:
  - Purchasing new shares
  - Redeeming existing shares

### For Closed-End Funds
- This NAV is a reference point
- Market price may be at premium or (more commonly) discount
- See: [[Closed-End Fund Discount Phenomenon]]
