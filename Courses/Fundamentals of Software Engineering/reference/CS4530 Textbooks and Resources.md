# CS4530 Textbooks and Resources

> [!info] Source
> <https://neu-se.github.io/CS4530-Fall-2026/textbooks/> and <https://neu-se.github.io/CS4530-Fall-2026/resources/>

**There is no single textbook** — the course surveys too many sub-areas of software engineering. Instead, several texts have relevant chapters, and the schedule lists which chapters go with which lecture.

## Getting O'Reilly Access (Free for NU Students)

1. Visit <https://www.safaribooksonline.com/library/view/temporary-access/>
2. Select **"Not Listed? Click Here"** for institution
3. Enter your `@northeastern.edu` email address

After creating the account once, you can log in directly with your Northeastern email — **no 2FA needed**.

## Core Texts

| Book | Why |
| --- | --- |
| [Software Engineering at Google](https://learning.oreilly.com/library/view/software-engineering-at/9781492082781/) — Winters, Manshreck, Wright | Effectively a manual of Google's SE practices and the rationale behind them |
| [Effective Software Testing: A Developer's Guide](https://www.effective-software-testing.com) — Aniche *(not on O'Reilly)* | Focused discussion of testing concepts with concrete Java examples |
| [The Programmer's Brain](https://www.manning.com/books/the-programmers-brain) — Hermans *(not on O'Reilly)* | Research on programming and cognition — reading code more effectively, writing code that's easier to read |
| [Fundamentals of Software Architecture](https://learning.oreilly.com/library/view/fundamentals-of-software/9781492043447/) — Richards, Ford | Architectural patterns and their role in successful projects |
| [Refactoring: Improving the Design of Existing Code](https://learning.oreilly.com/library/view/refactoring-improving-the/9780134757681/) — Fowler | The definitive list of code smells, matched to refactoring techniques |
| *Design Patterns: Elements of Reusable OO Software* (1994) — Gang of Four | Dated but foundational. Available from many sources |
| [Head First Design Patterns, 2nd Ed.](https://www.oreilly.com/library/view/head-first-design/9781492077992/) — Freeman & Robson | Free with the student O'Reilly subscription |
| [Learn React with TypeScript 3](https://learning.oreilly.com/library/view/learn-react-with/9781789610253/) — Rippon | React reference, through Router and testing |
| [Programming TypeScript](https://learning.oreilly.com/library/view/programming-typescript/9781492037644/) — Cherny | TypeScript intro assuming Java/C#/Python familiarity |

## By Topic

### Code Style → [[CS4530 Code Style Guide]]
- [To camelcase or under_score](https://ieeexplore.ieee.org/document/5090039) — Binkley et al *(paper)*
- [I know what you did last summer: how developers spend their time](https://dl.acm.org/doi/10.5555/2820282.2820289) — Minelli, Mocci, Lanza *(paper)*
- [A metric for software readability](https://dl.acm.org/doi/10.1145/1390630.1390647) — Buse and Weimer *(paper)*
- Fowler, *Refactoring* (above)

### Debugging → [[CS4530 Scientific Debugging]]
- [Effective Debugging: 66 Specific Ways to Debug Software and Systems](https://learning.oreilly.com/library/view/effective-debugging-66/9780134394909/) — Spinellis. Strategies matched to different kinds of debugging hypotheses

### Design Patterns
- [Design Patterns Explained](https://learning.oreilly.com/library/view/design-patterns-explained/0201715945/) — Shalloway and Trott
- [Refactoring to Patterns](https://learning.oreilly.com/library/view/refactoring-to-patterns/0321213351/) — Kerievsky. Unifies Gang of Four with Fowler, with practical examples of introducing patterns into existing code
- Richards & Ford, *Fundamentals of Software Architecture* (above)

### Infrastructure + Operations
- [Site Reliability Engineering](https://learning.oreilly.com/library/view/site-reliability-engineering/9781491929117/) — Beyer, Jones, Murphy, Petoff. Where SEs focus on design and development, SREs focus on deployment, monitoring, and maintenance. Documents Google's SRE practices

### JavaScript
- [Modern JavaScript for the Impatient](https://learning.oreilly.com/library/view/modern-javascript-for/9780136502166/) — Horstmann

### Program Understanding
- Hermans, *The Programmer's Brain* (above)
