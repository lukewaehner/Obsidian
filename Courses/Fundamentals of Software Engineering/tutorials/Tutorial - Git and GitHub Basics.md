# Tutorial — Git and GitHub Basics

> [!info] Source
> `Assignments/ip1/learning-github.md` in the course repo — linked from [[Individual Project 1]] as prerequisite reading if you're new to Git.

**Expectation**: all students can use **add / commit / push**.
**Where it's graded**: [[Team Project Overview]] — process (commits, PRs, code reviews) is 20% of the team project grade, and each member needs **≥2 commits per sprint**.

## Topics to Cover

- [ ] Git (distributed VCS) vs. GitHub
- [ ] The GitHub flow
- [ ] Repositories and READMEs
- [ ] [Cloning](https://docs.github.com/en/github/creating-cloning-and-archiving-repositories/cloning-a-repository)
- [ ] Committing and pushing — what makes a good commit message
- [ ] [Branches](https://docs.github.com/en/github/collaborating-with-issues-and-pull-requests/about-branches)
- [ ] [Forks](https://docs.github.com/en/github/getting-started-with-github/fork-a-repo) — the team project runs in a fork
- [ ] [Pull requests](https://docs.github.com/en/github/collaborating-with-issues-and-pull-requests/about-pull-requests) and review
- [ ] [Issues](https://docs.github.com/en/github/managing-your-work-on-github/about-issues) and [project boards](https://docs.github.com/en/github/managing-your-work-on-github/about-project-boards)
- [ ] [Markdown on GitHub](https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax)
- [ ] Profile / profile README

> [!note] IP1 is `main`-only
> [[Individual Project 1]] asks you to commit and push **only to `main`**. Branching and PRs become mandatory on the [[Team Project Overview|team project]].
