## 📊 Key Financial Models

### Capital Asset Pricing Model (CAPM)
```
E(Ri) = Rf + βi[E(Rm) - Rf]

Where:
- E(Ri) = Expected return on asset i
- Rf = Risk-free rate
- βi = Beta of asset i
- E(Rm) = Expected market return
```

### Bond Pricing
```
Price = Σ [C / (1 + r)^t] + [F / (1 + r)^T]

Where:
- C = Coupon payment
- r = Discount rate/YTM
- F = Face value
- T = Maturity
```

### Black-Scholes Option Pricing
```
Call = S₀N(d₁) - Ke^(-rT)N(d₂)
Put = Ke^(-rT)N(-d₂) - S₀N(-d₁)

Where d₁, d₂ involve stock price, strike, volatility, time, rate
```

- **Diversification**: Reducing unsystematic risk

- **Weak Form**: Past prices don't predict future
- **Semi-Strong Form**: Public info instantly reflected
