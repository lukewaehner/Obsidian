# Net Asset Value (NAV)

**Definition:** The net value of the assets held by a mutual fund divided by the number of shares outstanding.

## Formula

```
NAV = (Total Assets - Liabilities) / Number of Shares Outstanding
```

Or more specifically:
```
NAV = (Cash + Market Value of Securities - Liabilities) / Number of Shares
```

## Significance by Fund Type

### Open-End Funds
- Shares are **worth their NAV**
- Fund stands ready to redeem shares at any time at NAV
- Fund sells new shares at NAV
- **Price = NAV** always

### Closed-End Funds
- Share value **may differ from NAV**
- Typically trade at a discount to NAV
- See: [[Closed-End Fund Discount Phenomenon]]
- **Price ≠ NAV**

## Calculation Example

**Mulan Fund Data:**
- Cash: $0.3 million
- Liabilities: $0.2 million
- Stock positions:
  - Vibranium: 15,000 shares × $50 = $750,000
  - Uru: 25,000 shares × $60 = $1,500,000
  - Adamantium: 12,000 shares × $100 = $1,200,000
- Fund has 100,000 shares outstanding

**Calculation:**
```
Total Stock Value = $750,000 + $1,500,000 + $1,200,000 = $3,450,000
Total Assets = Cash + Stock Value = $300,000 + $3,450,000 = $3,750,000
Net Assets = Total Assets - Liabilities = $3,750,000 - $200,000 = $3,550,000

NAV = $3,550,000 / 100,000 shares = $35.50 per share
```

See: [[NAV Calculation]] for more examples

## When NAV is Used

### Pricing Transactions
- [[Open-End Funds]]: All purchases and redemptions occur at NAV
- [[Closed-End Funds]]: NAV is reference point, but trading occurs at market price

### Performance Measurement
- Changes in NAV reflect fund performance
- Before fees and expenses

### Reporting
- Funds report NAV daily
- Required disclosure in prospectus and reports

## Special Cases

### Money Market Mutual Funds
- Historically maintained **$1.00 NAV** to resemble bank accounts
- No guarantee NAV will be $1.00 or more
- NAV below $1.00 = "[[Breaking the Buck]]"

## What Affects NAV?

1. **Market Value Changes** - Securities appreciate/depreciate
2. **Dividends/Interest** - Income increases assets
3. **Distributions** - Payments to shareholders decrease NAV
4. **Expenses** - Operating costs reduce net assets
5. **Fund Flows** - Not applicable (purchases/redemptions happen at NAV)
